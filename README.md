# Smart ASCII Studio — Vercel version

A browser-based image-to-ASCII converter built with HTML, CSS and JavaScript.

## Features
- Upload JPG, PNG and WEBP images
- ASCII width control
- Standard, Detailed, Simple and Blocks character styles
- Brightness inversion
- Adaptive contrast
- Edge-aware enhancement
- Normal vs Enhanced comparison mode
- TXT and PNG downloads
- Responsive dark navy/purple interface

## Deploy on Vercel
Import this repository and choose **Other** as the Framework Preset. Leave Build Command and Output Directory blank. The `index.html` file must be in the repository root.

All image processing happens locally in the browser using the Canvas API. No Python backend is required.
